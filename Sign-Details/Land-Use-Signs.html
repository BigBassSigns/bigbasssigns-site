Land use & public notice

Land use signs posted on time — without you learning every city’s spec.

Public notice boards and land use action signs for King County Permitting, Snohomish County PDS, and nearby cities. You forward the Notice of Application. We print the board, set the posts, and send the photo for the affidavit of posting.

Email the notice package

Built for planners, developers, and engineers

The completeness letter gives you a short clock. The board has to match the packet. That changes by city and county. You should not have to keep a binder of those rules. That is the shop’s job.

Send the site address, the file number, and the notice PDF. We build the land use sign that packet actually calls for and we install it so the comment period can start on time.

You get a readable board in Western Washington rain and a photo for the affidavit. If wind or graffiti takes it down, we put it back up. When the planner releases it, we pull the posts.

What we handle

  • Land use action signs and public notice boards
  • Weatherproof faces on MDO or exterior plywood
  • Clear lamination for PNW rain
  • Post-setting and a plumb board
  • Install photo for the affidavit of posting
  • Repair and removal
